# 投資人風險評估

一個機器人理財顧問（Robo-Advisor）小專案，用兩段問卷幫使用者畫出風險輪廓：先用十題選擇題評估傳統財務風險承受度，再用六題開放式問題觀察面對市場波動時的行為與情緒反應。兩段問卷中間不中斷，全部作答完才會在同一頁一次顯示結果。作答前先輸入暱稱，完成後結果會連同暱稱送到後端記錄。

## 執行

後端是零相依套件的 Node 伺服器（需 Node 20.12 以上），同時提供前端頁面：

```bash
npm start
```

開啟 http://127.0.0.1:3000 即可。

### 啟用 AI 分析（選用）

第二階段預設用內建的關鍵字比對。若要改用 LLM 做語意分析：把 `.env.example` 複製成 `.env`，填入 `LLM_API_KEY`（預設連長庚 CGU API，網址與模型可用 `LLM_BASE_URL`、`LLM_MODEL` 改成其他 OpenAI 相容服務），重新 `npm start`。沒有金鑰、額度用完或 API 出錯時，會自動退回關鍵字版，結果頁會標示這次用的是哪一種分析。金鑰只存在後端，`.env` 不會被提交。

結果存在 `data/submissions.json`（已加入 `.gitignore`）：`POST /api/submissions` 寫入一筆，`GET /api/submissions` 列出全部。可用 `PORT`、`HOST` 環境變數調整；預設只監聽本機，因為 GET 沒有身分驗證。直接開啟 `index.html` 仍可作答，但結果頁會提示未記錄到後端。

## 分數計算邏輯

### 傳統風險評估（第一階段）

十個題目——年齡、收入、資產、投資期限、投資目標、損失承受能力、風險偏好、提款需求、金融商品知識、投資經驗——每題五個選項，分別對應 1 到 5 分（1 分最保守，5 分最積極）。

各題權重不同（合計 100%），讓「賠不賠得起」的客觀條件比主觀意願更重要：

| 題目 | 權重 | 理由 |
| --- | --- | --- |
| 損失承受能力、提款需求、投資期限（各 15%） | 45% | 決定能不能承受資產縮水與波動的硬性限制 |
| 年齡、資產、收入（各 10%） | 30% | 財務緩衝與再賺取能力 |
| 投資目標、風險偏好（各 7.5%） | 15% | 主觀意向，需受客觀條件約束 |
| 金融商品知識、投資經驗（各 5%） | 10% | 輔助參考：懂金融不代表賠得起 |

1. 把各題分數乘上權重再加總，除以權重總和，得到 1–5 分的「加權平均分數」（四捨五入到小數兩位）。
2. 加權平均換算成 0–100 分的「基準風險分數」：`(加權平均 − 1) ÷ 4 × 100`。
3. 依加權平均對照門檻（把 1–5 分量表三等分，與題目數量無關），判定投資人類型。區間為左閉右開，剛好等於門檻時歸入較積極的一型：

   | 加權平均分數 | 投資人類型 |
   | --- | --- |
   | 小於 2.34 | 保守型 |
   | 2.34 以上、小於 3.68 | 穩健型 |
   | 3.68 以上 | 積極型 |

#### 上限規則（取較保守者）

加權平均仍會讓高分題補償低分題，所以在上面算出的類型之外，再套兩種「只降不升」的上限，最終類型取其中最保守的一個：

1. **能力構面上限**：把六個客觀能力題（年齡、收入、資產、投資期限、提款需求、損失承受能力）單獨做加權平均，用同一組門檻轉成類型；整體類型不能比它更積極。
2. **單題硬性上限**：「投資期限」選 1 年以內、「提款需求」選沒有其他資金又需要提款、「損失承受能力」選下跌 20% 會嚴重影響生活，任何一項成立，類型最高為穩健型，不管其他題答什麼。

類型被調降時，結果頁會同時顯示調整前與調整後的類型和原因；基準風險分數不隨上限調整。

例如：能力類題目全部是最低分、意願與經驗類全部是最高分的受測者，加權平均為 2.0，判定保守型（等權平均會是 2.6，落入穩健型）；其他題全部最高、只有「提款需求」選最差的受測者，加權平均 4.4（積極型），被單題上限調整為穩健型。

### 行為與情緒評估（第二階段）

六題開放式問題，讓使用者用自己的話描述會怎麼反應。預設的分析方式是純前端的關鍵字比對（下面描述的規則）；啟用 AI 分析時，則改由 LLM 依語意給每個指標 1–5 分，並附上依據原句與信心度，之後的提醒規則相同：

1. 把六題的回答文字合併，比對七個指標（焦慮、損失規避、自信程度、從眾傾向、過度自信、確認偏誤、處置效應）各自的關鍵字清單，分成「會提高分數」與「會降低分數」兩組（同時保留中、英文寫法）。
2. 每個指標從 3 分（中性）出發，比對到的「提高」關鍵字每種加 0.8 分、「降低」關鍵字每種減 0.8 分，最多各算 3 種，四捨五入後限制在 1–5 分之間。
3. 分數最高的指標列為「主要情緒訊號」；若特定指標組合偏高（例如焦慮與損失規避同時偏高），會額外顯示對應的行為提醒。
4. 如果回答文字太短、或完全沒比對到任何關鍵字，畫面會提示分析結果僅供參考。

### 結果頁

作答全部完成後，同一頁由上而下顯示：投資人類型（保守型／穩健型／積極型）與基準風險分數、十個風險構面的雷達圖與逐題作答；接著是主要情緒訊號、七個行為情緒指標的雷達圖與分數，以及行為提醒。結果可下載成 JSON 檔。
